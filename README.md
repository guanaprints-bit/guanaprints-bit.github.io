# Guanaprints: configuración de raíz

Este repositorio publica https://guanaprints-bit.github.io/ mediante GitHub Pages.

- `robots.txt` debe servirse en la raíz del dominio. Referencia el sitemap del catálogo.
- El catálogo y su sitemap se mantienen en el repositorio separado `guanaprints-bit/catalogos-guanaprints`.
- No copiar ni trasladar aquí las fichas de producto.
- La portada enlaza al catálogo y lleva `noindex,follow` para no competir con él.
- No configurar un dominio personalizado: conservar las direcciones actuales del catálogo.
